# Synth Browser

Synth Browser is a Rust + Tauri desktop browser project. The native shell and application services are Rust/Tauri; browser content runs in an isolated runtime integration. The Windows-first runtime uses Tauri's WebView2-backed webview while the Azecotron Web Chromium fork remains a documented integration milestone.

Search technology: Cortis (provider-backed adapter architecture).

## Status

Core shell implementation is being built incrementally. Unsupported features are documented rather than represented by mock controls.
