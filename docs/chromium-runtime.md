# Azecotron Web status

Product/runtime name: Azecotron Web

v0.1.0 status: BLOCKED / DESIGNED.

Windows uses Tauri's WebView2-backed webview. macOS/Linux use their supported native webview implementations. The application does not claim that these are the Azecotron Chromium fork.

A true fork requires a reproducible Chromium source revision, patch set, security update cadence, sandbox validation, licensing notices, and a verified build pipeline. Those are not bundled in v0.1.0.
